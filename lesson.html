    Take it into your DAW

    Ableton Live · Logic Pro · Pro Tools

    1 · Export MIDI

    “All tracks” makes one file with Chords, Bass and Melody on separate tracks, with tempo and key included.

    How to open it in your DAW
    Ableton Live
    Drag the .mid file from Finder or Explorer into the Arrangement View: each track becomes its own MIDI track. Drop an instrument on each (e.g. Grand Piano, a pad, Operator for bass). Set the project tempo to match.
    Logic Pro
    Drag the file into the Tracks area, or use File → Import → MIDI File. Logic asks whether to import the tempo: say yes. Choose a Software Instrument for each track.
    Pro Tools
    File → Import → MIDI. Choose “New track” and the Instrument track type, and import the tempo map. Insert a virtual instrument on each track.

    Bringing it back: export the MIDI of each part. You can attach several .mid files at once.

    Ableton Live
    Select a clip, then File → Export MIDI Clip. Repeat for each track (consolidate long arrangements into one clip per track first). Export the mix with File → Export Audio/Video.
    Logic Pro
    Select the regions, then File → Export → Selection as MIDI File. Bounce with File → Bounce → Project or Section.
    Pro Tools
    File → Export → MIDI. Bounce with File → Bounce Mix.
